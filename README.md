# forkids (dipindah)

Kebun Hitung dan Latihan Ujian kelas 1 dan 2 sekarang ada di **Abaqa**: repo [cexagon/abaqa](https://github.com/cexagon/abaqa), situs https://cexagon.github.io/abaqa/.

Repo ini hanya menyisakan halaman pengalih: setiap alamat lama `cexagon.github.io/forkids/...` dibuka di alamat barunya di Abaqa, dan service worker lama menghapus cache lamanya lalu melepas diri. Riwayat lengkap tetap ada di git.
