# Kebun Hitung

Game belajar bilangan untuk anak kelas 1 SD (Matematika Fase A, Kurikulum Merdeka).
Bantu Kancil melayani pembeli di Warung Tebu: hitung, ikat sepuluhan, dan kirim.

- 5 bab: bilangan sampai 10, sampai 20, penjumlahan, pengurangan, puluhan dan satuan sampai 99
- Umpan balik yang menjelaskan (Kancil mengajak menghitung ulang), tanpa tanda silang
- Bisa dipasang di Android dan iPhone sebagai aplikasi (PWA), jalan offline setelah dibuka sekali
- Tanpa iklan, tanpa akun, data tersimpan di perangkat

## Menjalankan di GitHub Pages

1. Buat repositori baru di GitHub, misalnya `kebun-hitung`, lalu unggah semua file di folder ini (termasuk folder `css`, `js`, `icons`).
2. Buka **Settings → Pages**, pada *Build and deployment* pilih **Deploy from a branch**, branch `main`, folder `/ (root)`, lalu **Save**.
3. Tunggu sekitar satu menit. Alamatnya: `https://<username>.github.io/kebun-hitung/`.
4. Buka alamat itu di HP: Android (Chrome) → menu ⋮ → **Pasang aplikasi**; iPhone (Safari) → **Bagikan** → **Tambahkan ke Layar Utama**.

Semua jalur file sudah relatif, jadi bisa juga dipasang di Cloudflare Pages, Netlify, atau subfolder situs mana pun.
